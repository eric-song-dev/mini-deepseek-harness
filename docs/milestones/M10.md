# M10 —— web search 插件（可插拔能力的示范：第一个外部 HTTP 工具）

- **状态**：`proposed`（2026-08-18 定稿；上游调研见 `.agents/notes/proposed/2026-08-18-m10-web-search-上游调研.md`）
- **前置**：M0–M9（已完成）。直接依赖：M3（Tools seam + 执行管线）、M6（注册可逆）、M2（LLM adapter 的假 HTTP 端点测试模式）。
- **定位**：用户指定新增项。**可插拔机制已实现（M0 profile 装载 + M3 工具插件 + M6 注册可逆），本 M 不做基建**，而是用它落地 web search 能力：上游"一组 provider 插件 + `web_search` 工具暴露给模型"三层架构的 mini 版。这是 mini 的第一个**外部 HTTP 工具插件**，也是第一个**多 provider 注册表 + 执行时选择**的 seam（LLM seam 目前是单 adapter）。

## 目标

1. **web 能力 seam（`ctx.web`）**：`WebRuntime` 服务——`registerSearchProvider`
   （重 id 抛 `WEB_DUPLICATE_PROVIDER`，返回幂等撤销函数，M6 纪律）+ `search(request,
   signal?)`；**执行时提供方选择**（配置 id / 唯一可用 / 歧义 / 缺失，六支全做）；seam
   在返回路径强制执行 `maxResults`（截断 `sources[]` + `truncated`）。
2. **两个提供方插件**：`fakeWebSearch`（台词本假提供方，零 key demo/测试）+
   `deepseekWebSearch`（真提供方：Anthropic 兼容 Messages API + 原生 `web_search_20250305`
   服务器工具 + 结构化 `web_search_tool_result` 块解析 + 严格模式，零 key 测试走本地
   假 HTTP 端点）。提供方注册的是**能力**而非工具。
3. **消费方 `webSearchTool` 插件**：`web_search` 工具注册进现有 Tools seam（`query`
   参数 + 结构化结果"可选答案 + sources 列表"）；**稳定注册**——provider 缺失/不可用时
   工具仍在，执行返回模型可读的 `{ error }` 结果（mini 的"输出是内容、异常是结果"
   语义，skill 工具同款）；工具绝不调用 `available()`、绝不枚举提供方。
4. **零 key 闭环**：假 LLM 台词本驱动 `web_search` → fakeWebSearch 返回固定结果 →
   tool 事件入轨迹可回放；HMR-safety 测试（卸载 provider 插件 → 选择行为回到未注册态，
   卸载 tool 插件 → 工具消失）。
5. **Web 可见路径（M8 教训）**：demo:web 共享 runtime 挂 webRuntime + webSearchTool +
   双模式各自 provider（fake 模式 = fakeWebSearch；real 模式 = deepseekWebSearch），
   浏览器 tool 卡片可见 web_search 场景；client 零改动。

## 包与 seam 契约

新包 `packages/web-search`（`@mini-dsh/web-search`）。三层拆分在包内文件边界体现
（mini 包粒度 = 子系统粒度，M9 同款；换 provider = 加一个文件 + profile 加一行）：

- `src/web.ts` —— Service Definition（能力 seam 本体）：
  ```ts
  export interface WebSearchSource { url: string; title?: string; snippet?: string; publishedAt?: string }
  export interface WebSearchRequest { query: string; maxResults?: number }
  export interface WebSearchResult { content?: string; sources: WebSearchSource[]; truncated: boolean }
  export interface WebSearchProvider {
    id: string
    available(): boolean                      // 廉价本地检查，禁止网络调用
    search(request: WebSearchRequest, signal?: AbortSignal): Promise<WebSearchResult>
  }
  export interface WebRuntime {               // 服务键 'web'
    registerSearchProvider(provider: WebSearchProvider): Unregister
    search(request: WebSearchRequest, signal?: AbortSignal): Promise<WebSearchResult>
  }
  export class WebError extends Error { readonly code: string }
  export const webRuntime: Plugin             // ctx.provide('web', createWebRuntime(config))
  ```
  - **选择语义（执行时解析，绝不依赖注册顺序）**：配置 id（webRuntime config
    `searchProvider`）已注册且 `available()` → 用它；配置 id 未注册 →
    `WEB_PROVIDER_CONFIGURED_MISSING`；已注册但不可用 →
    `WEB_PROVIDER_CONFIGURED_UNAVAILABLE`；无 id 且唯一可用 → 用它；无 id 多可用 →
    `WEB_PROVIDER_AMBIGUOUS`（消息含候选 id 集）；无可用 → `WEB_PROVIDER_UNAVAILABLE`。
  - **maxResults 强制**：返回前 `sources.length > maxResults` → slice + `truncated: true`
    （`truncated = 提供方值 || 本次截断`）；`content` 原样透传。
  - **WebError 码表**（open code string）：`WEB_PROVIDER_UNAVAILABLE` /
    `WEB_PROVIDER_CONFIGURED_MISSING` / `WEB_PROVIDER_CONFIGURED_UNAVAILABLE` /
    `WEB_PROVIDER_AMBIGUOUS` / `WEB_DUPLICATE_PROVIDER` / `WEB_ABORTED` /
    `WEB_PROVIDER_ERROR` / `WEB_PROVIDER_CREDENTIAL_MISSING`。
  - signal 透传给选中 provider（seam 本身不制造取消）。
- `src/fake.ts` —— fakeWebSearch：id `'fake'`，`available()` 恒 true；台词本 config
  `results?: WebSearchResult[]`（按序消费，耗尽抛 `FakeWebSearchExhaustedError`——
  fakellm 同款"防止静默空转"纪律）；无 config 用内置固定结果。
- `src/deepseek.ts` —— deepseekWebSearch：id `'deepseek-official'`（上游同款）；
  `inject: ['web']`；config（默认值全部上游同款）：
  `apiKey?` / `apiKeyEnv?`（默认 `DEEPSEEK_API_KEY`）/ `baseURL?`（默认
  `https://api.deepseek.com/anthropic/v1`，env `DEEPSEEK_SEARCH_BASE_URL` 兜底，
  **不复用 `DEEPSEEK_BASE_URL`**）/ `model?`（`deepseek-v4-flash`）/ `apiVersion?`
  （`2023-06-01`）/ `maxTokens?`（4096）/ `maxUses?`（5）/ `fetch?`（假 HTTP 测试注入，
  llm adapter 同款）。
  `available()` = key 可解析 && `URL.canParse(baseURL)` && maxTokens/maxUses 正整数。
  `search()`：POST `{baseURL}/messages`，body `{model, max_tokens, messages:[{role:
  'user', content:[{type:'text', text:'Perform a web search for the query: <query>'}]}],
  tools:[{type:'web_search_20250305', name:'web_search', max_uses}]}`；headers 同时发
  `x-api-key` 与 `Authorization: Bearer` + `anthropic-version`；`redirect: 'error'`；
  错误映射（abort → `WEB_ABORTED` 'DeepSeek search aborted'；fetch 失败 → 
  `WEB_PROVIDER_ERROR` 'DeepSeek search request failed: <error>'；HTTP 非 ok → 解析
  AnthropicError detail；body 不可解析 → 'DeepSeek returned an unprocessable response
  body: <error>'；无 key → `WEB_PROVIDER_CREDENTIAL_MISSING`）；映射：过滤
  `web_search_tool_result` 块 → 无块抛严格模式错误 → citationSnippets（text 块
  `citations[]` 首见胜，按 URL 关联 snippet）→ 按 URL 去重 → 空字段省略 →
  `{ sources, truncated: false }`（`content` 省略——提供方答案不受信任）。
- `src/tool.ts` —— webSearchTool（消费方）：`inject: ['tools', 'web']`；config
  `{ searchMaxResults?: number (默认 8), searchTimeoutMs?: number (默认 30000) }`。
  声明：name `web_search`；description 'Search the web for current information.
  Returns an optional summary answer and a list of source URLs. Use the returned
  source snippets when available, and cite the relevant URLs as markdown links.'
  （上游 description + 仅搜索指引的 cite 句——mini 无 system-prompt seam，指引并进
  description）；parameters `{type:'object', properties:{query:{type:'string',
  description:'The search query.'}}, required:['query']}`（上游 catalog 同款）。
  execute：query trim 空 → `{ error: 'query must be a non-empty string' }`；自建
  AbortController + setTimeout(searchTimeoutMs) 作 signal（finally 清定时器）→
  `ctx.web.search({ query, maxResults }, signal)`；`WebError` → `{ error: message }`
  （稳定注册：不 crash）；成功 → 结构化结果原样返回（轨迹面板展示 result JSON）；
  其他意外错误上抛。注册无条件执行 + ctx.effect 挂接（M6）。

配置落点 = profile.yml 插件 options（kernel 零改动）。

## 教程主题（§5.1 六要素）

`docs/tutorials/M10-web-search.md`：动机（第一个外部 HTTP 工具；为什么能力 seam 要
三层拆分、为什么排在 M9 后——M9 是"外部工具的注册桥"，M10 是"能力 + 多提供方 + 
执行时选择"的完整示范）；design（三层拆分图 + 选择语义 + plantUML：类图 + 搜索时序图）；
新概念（能力 seam、provider 注册表、执行时选择 vs 注册顺序、available() 本地检查、
稳定注册、Anthropic 兼容 Messages API、假 HTTP 端点测试）；tradeoff（为什么提供方
注册能力而非工具、为什么选择在执行时解析、为什么稳定注册（工具在错误在后）vs 启动
即失败、maxResults 为什么是部署设置不是模型参数、单包 vs 上游拆包）；stepbystep
（web.ts seam → fake.ts → tool.ts → deepseek.ts → e2e → demo）；练习（写自己的
provider 注册进 webRuntime：断言唯一自动选择 + 截断 + 红绿翻转，零 key）。

- `output.render` 层 / `presentationMeta` / `card: 'web'` UI 卡片（mini 客户端只有通用
  tool 卡片；工具返回结构化结果，轨迹面板展示 result JSON）
- perplexity / exa 提供方、Web 配置 UI（profile.yml 配置项即可）
