## 目标（概览，定稿时拆解为 TDD 任务）

1. **todo 子系统（核心资产，完整照做）**：`TodoItem` 类型 + `todo/write` 事件（整表快照、last-wins、log-only）+ `todo_write` 工具（注册进现有 Tools seam，返回 `{todos, counts}`）。
2. **plan 子系统（布尔模式开关 + 引导）**：`plan/mode` 事件 + `ctx.planMode` 服务（`get()` fold 最近一次事件 / `set(active)` 立即 append，无 pending 状态机）+ `plan:policy` 提示词段（激活时拼进 system prompt）。
3. **Web 最小展示**：todo 列表面板（读会话日志 fold 最近一次 `todo/write`）+ plan 开关按钮（RPC 调 `planMode.set`）。
4. **注册可逆（M6 纪律）**：todo_write 工具与 planMode 服务的注册全部可撤销 + HMR-safety 测试；`todo/write`、`plan/mode` 事件入日志可回放。

**验收（草案）**：模型用 `todo_write` 建表并整表替换、任务全程可投影回放；plan 开关切换后 system prompt 同步注入/移除 policy 段；卸载相关插件后工具与事件能力消失；零 key 可 demo。

## 裁剪决定（草案，定稿时逐条核对）

**做（教学最小集合）**：

- `TodoItem { content, status: 'pending'|'in_progress'|'completed' }`（有意最小：无 id、整表替换）
- `'todo/write'({ todos })` 整表快照事件 + `todo_write` 工具（`additionalProperties: false` 严校验；非 agent 调用方拒绝；`allowParallelInProgress` 开关教学上给默认值，避开上游"必填无默认"的坑）
- `'plan/mode'({ active })` 事件 + `ctx.planMode`（get/set 立即 commit，不做 `committed/queued/cancelled/noop` 四态）
- `plan:policy` 提示词段：`base + 时间 + (planMode.get() ? policy : '')`
- Web：todo 面板 + plan 开关（复用现有 session/append 推送 + 会话日志 fold）

**砍掉（mini 无对应 seam，不值得先造）**：

- goal 联动（完全不做）
- `agent/pre-step` pending-intent 状态机（mini loop 串行，立即 commit 即可）
- `/plan` 命令与 commands 注册表（Web 按钮 + RPC 替代）
- `exit_plan_mode` 的 userQuestions 评审流（若保留退出工具则简化为"校验 plan mode + 直接退出"，无批准流）
- `sessionProjections` 注册表（用独立 fold 函数代替：最近一次 `todo/write`、`foldPlanMode` 等价物）
- presentCall 卡片、KV-cache 推理、i18n、双命名空间出口
