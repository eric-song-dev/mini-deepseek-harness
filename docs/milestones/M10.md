# M10 —— web search 插件（可插拔能力的示范：第一个外部 HTTP 工具）

- **状态**：`draft`（占位概览；开工 session 按下方"上游必读索引"读完上游后定稿，定稿后置 `proposed`）
- **前置**：M0–M9（已完成）。直接依赖：M3（Tools seam + 执行管线）、M6（注册可逆）、M2（LLM adapter 的假 HTTP 端点测试模式）、M7（可选：技能体系）。
- **定位**：用户指定新增项。**可插拔机制已实现（M0 profile 装载 + M3 工具插件 + M6 注册可逆），本 M 不做基建**，而是用它落地 web search 能力：上游"一组 provider 插件 + `web_search` 工具暴露给模型"三层架构的 mini 版。这是 mini 的第一个**外部 HTTP 工具插件**，也是第一个**多 provider 注册表 + 执行时选择**的 seam（LLM seam 目前是单 adapter）。

## 目标（概览，定稿时拆解为 TDD 任务）

1. **web 能力 seam（`ctx.web`）**：`registerSearchProvider`（返回幂等撤销函数，M6 纪律）+ `search(request, signal?)`；执行时提供方选择（配置 id / 唯一可用 / 歧义报错）；seam 强制执行 `maxResults`（截断 + `truncated`）。
2. **两个提供方插件**：`deepseekWebSearch`（真提供方：Anthropic 兼容 Messages API + 原生 web_search 服务器工具，结构化结果映射，零 key 测试走本地假 HTTP 端点）+ `fakeWebSearch`（台词本假提供方，零 key demo/测试）。
3. **消费方 `webSearchTool` 插件**：`web_search` 工具注册进现有 Tools seam（`query` 参数 + 结果"答案 + Sources 列表"格式）；**稳定注册**——provider 缺失/不可用时工具仍在，执行返回模型可读的 `{ error }` 结果（mini 的"输出是内容、异常是结果"语义）。
4. **零 key 闭环**：假 LLM 台词本驱动 `web_search` 工具 → fakeWebSearch 返回固定结果 → tool 事件入轨迹可回放；HMR-safety 测试（卸载 provider 插件 → 选择行为回到未注册态）。

**验收（草案）**：profile 加两行（seam + provider + tool 的插件行）即可获得 web_search 能力，loop/kernel 零改动；`fakeWebSearch` 路径零 key 全链路可跑可回放；`deepseekWebSearch` 经本地假 HTTP 端点测试真 HTTP 链路与结果映射；重 id 注册报错、卸载即撤销、maxResults 截断、歧义选择报错各有契约测试。

## 已核实的上游事实（定稿时直接引用，不必重查）

- **三层拆分**：Service Definition（`ctx.web`：提供方注册表 + 选择策略 + 词汇 + WebError）→ Provider 插件组（deepseek / perplexity / exa，注册**能力**而非工具）→ Consumer（`tool-web`：面向模型的 `web_search`/`web_fetch` 名称、schema、提示词、呈现的唯一归属方）。换提供方不改模型提交查询的方式。
- **选择语义（执行时解析，绝不依赖注册/配置/HMR 顺序）**：配置 id 已注册且 available → 用它；配置 id 未注册 → `WEB_PROVIDER_CONFIGURED_MISSING`；注册但不可用 → `WEB_PROVIDER_CONFIGURED_UNAVAILABLE`；无 id 且唯一可用 → 用它；无 id 多可用 → `WEB_PROVIDER_AMBIGUOUS`；无可用 → `WEB_PROVIDER_UNAVAILABLE`。`available()` 是廉价本地检查（凭据/配置），**禁止网络调用**。
- **seam 契约**：`registerSearchProvider(provider): () => void`（重 id → `WEB_DUPLICATE_PROVIDER`，disposer 随 fiber 撤销——与 mini M6 完全同构）；`search(WebSearchRequest{query, maxResults?}, signal?)` → `WebSearchResult{content?, sources[], truncated}`；`WebSearchSource{url, title?, snippet?, publishedAt?}`（url 必填，其余可缺——不强迫提供方编造）。seam 在返回路径强制执行 maxResults。
- **稳定注册**：工具注册跟随产品启用状态而非后端可用性——provider 缺失/错误配置/暂不可用，`web_search` 仍注册；执行时抛结构化 `WebError`，工具转为模型可读错误结果。工具绝不调用 `available()` 或枚举提供方。
- **结果格式（模型可见）**：可选答案 → `Sources:` 后 `- [<title-or-url>](<url>) — <snippet> (<publishedAt>)` 行；无答案无来源 → `No results found.`；截断时加 `(Showing the first <count> sources. ...)`；结尾 `Cite the relevant URLs above as markdown links in your answer.`。
- **deepseek 提供方要点**：Anthropic 兼容 Messages API（`POST {baseURL}/messages`，默认 `https://api.deepseek.com/anthropic/v1`，**不复用** `$DEEPSEEK_BASE_URL`）+ 原生 `web_search_20250305` 服务器工具；解析结构化 `web_search_tool_result` 块（**绝不从模型文本抓 URL**）；无块 → 严格模式抛 `WEB_PROVIDER_ERROR`（不降级）；结果按 URL 去重；maxResults 由 seam 截断。
- **配置**（tool-web）：`searchMaxResults` 默认 8；`searchTimeoutMs` 默认 30000（不面向模型——模型只给 query）。`max_results` 有意不做成模型参数（部署设置）。

## 裁剪决定（草案，定稿时逐条核对）

**做（教学最小集合）**：

- `ctx.web` 只做 **search**（`web_fetch` 与 fetch 提供方留 backlog，定稿拍板是否顺带）；
- 选择策略做全（配置 id / 唯一 / 歧义 / 缺失四支），它是本 seam 的核心教学点；
- `WebError` 精简码表：`WEB_PROVIDER_UNAVAILABLE` / `WEB_PROVIDER_AMBIGUOUS` / `WEB_DUPLICATE_PROVIDER` / `WEB_PROVIDER_ERROR` / `WEB_ABORTED`（`CONFIGURED_*` 两支视配置支持度定夺）；
- 提供方：`fakeWebSearch`（台词本）+ `deepseekWebSearch`（真端点 + 假 HTTP 测试）；凭据直接读 `DEEPSEEK_API_KEY`（不做 credentials seam）；
- 消费方：`web_search` 单工具（search 指引提示词段按"仅搜索"分支）；结果渲染 "answer + Sources" 格式；
- 零 key demo：fakeWebSearch + fakellm 台词本；注册可逆 + HMR-safety 测试。

**砍掉（mini 无对应 seam/不值得先造）**：

- `web_fetch`、HTML→markdown（turndown）、`web-fetch-http` 提供方、fetch 安全策略（URL 校验/重定向/字节上限）；
- credentials seam（密钥轮换/Models 页）、settings 层叠加语义（apiKey role('secret')）；
- `web/deepseek-search-llm-request` 请求日志事件（可留一行注释：mini 的 tool 事件已记调用，辅助请求体日志可后置）；
- `output.presentationMeta` + `card: 'web'` UI 卡片（mini 客户端只有通用 tool 卡片；轨迹面板展示 result JSON 即可）；
- perplexity / exa 提供方、`searchProvider` 配置 UI（profile.yml 配置项即可）。

## 迷你 seam 草案（定稿时写进契约测试）

```ts
// 新包 packages/web-search（服务键 'web'，与上游对齐；定稿时核对 mini 无 'web' 键冲突——
// mini 的 packages/web 提供的是 rpcBridge/sessionManager，无 'web' 服务）
interface WebSearchSource { url: string; title?: string; snippet?: string; publishedAt?: string }
interface WebSearchRequest { query: string; maxResults?: number }
interface WebSearchResult { content?: string; sources: WebSearchSource[]; truncated: boolean }

interface WebSearchProvider {
  id: string
  available(): boolean                       // 廉价本地检查，禁止网络调用
  search(req: WebSearchRequest, signal?: AbortSignal): Promise<WebSearchResult>
}

interface WebRuntime {                        // ctx.web
  registerSearchProvider(p: WebSearchProvider): Unregister  // 重 id → WebError WEB_DUPLICATE_PROVIDER；M6 可逆
  search(req: WebSearchRequest, signal?: AbortSignal): Promise<WebSearchResult>  // 执行时选择；maxResults 强制
}
class WebError extends Error { readonly code: string }

// 消费方：webSearchTool 插件（inject ['tools','web']）→ ctx.tools.register（ctx.effect）
// 稳定注册：provider 缺失时工具仍在，execute 捕获 WebError → 返回 { error } 结果（M3 语义）
// 提供方：deepseekWebSearch（inject ['web']，Anthropic 端点 + web_search 服务器工具 + 块解析 + 严格模式）
//         fakeWebSearch（台词本；available() 恒 true）
```

配置落点定稿时拍板：`profile.yml` 插件 options（`searchProvider: 'deepseek'`、`searchMaxResults: 8` 等）。
