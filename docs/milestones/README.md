# 里程碑 specs

每个里程碑 M 的**详细执行 spec** 放这里：`M<n>.md`，M0–M5 各有一份。

- `docs/requirements.md` §9 是里程碑概览表（一 M 一行），只做导航。
- 本目录是当前 M 的**唯一执行依据**：任务拆解、TDD 顺序、验收、教程要求、完成后收尾动作。
- **生命周期**：`draft`（占位，只有概览）→ `proposed`（当前 M，已定稿）→ `implemented`（完成归档）。
- **定稿时机（防过度设计）**：`M<n>.md` 由**上一个 M 收尾时的 session** 定稿（拆解任务、验收、教程），记入 notes，用户可审查；定稿后状态改为 `proposed`。不在需求阶段提前写后续 M 的细节。
