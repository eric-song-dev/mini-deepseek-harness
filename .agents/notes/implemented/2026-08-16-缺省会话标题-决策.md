# 缺省会话标题：host 层补默认标题（2026-08-16）

## 背景

`pnpm demo:web --clean` 后点「＋ 新建会话」，左侧列表项只有蓝色高亮、没有名字。
根因：client 的 `store.create()` 不传 title → `webHost` 原样透传 → JSONL 后端
`title: input.title ?? ''` 落成空字符串，列表渲染空标题。

## 决策：默认标题由 host 补，不改 SessionPersistence seam

- `store.ts` 既有注释早已声明 "title 缺省由 host 补默认标题"，本次补齐实现，
  兑现该承诺：`webHost` 的 `session.create` 里 `title` 为 undefined 或空串时补
  `新会话 08-16 14:32`（分钟粒度，并存会话可区分）。
- 不放进 JSONL 后端的原因：默认标题是"门面行为"而非"存储行为"——放进后端会
  要求修改已发布的 `SessionPersistence` 契约测试，并让将来 SQLite 等每个后端
  各自重复实现；放 host 层换后端零改动。

## 测试

- host 层（`packages/web/tests/host.test.ts`）：缺省 title 与空串 title 都补默认
  标题，且 `session.list` 与 create 返回一致。
- UI 层（`packages/client/tests/ui.test.tsx`）：点「＋ 新建会话」后左侧列表项
  显示会话名字。
- 实链路复验：真 HTTP+WS 栈上不带 title 的 `session.create` 返回
  `新会话 08-16 12:40`，列表一致。
