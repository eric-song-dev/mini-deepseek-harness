## 决策（每项：改了什么 + 为什么）

### 1. 工具执行错误回填模型（不再整轮 crash）

- **改法**：`packages/agent/src/loop.ts` 把 `tools.execute` 的任何 rejection 归一化成
  `{isError:true, content: String(error)}` 结果事件回填模型，轮次继续；模型看到失败原因
  可自行纠正（与 bash 的 exit code、MCP 的 isError 同款纪律）。LLM 等其他异常仍走
  `turn/end(crash)`；maxSteps 仍走 `limit`。
- **影响**：未知工具/工具抛错不再是整轮报废；workflow 工具的 fatal 错误同样以 isError
  结果到达模型（M8 e2e 测试与 demo 叙事已同步改：父轮次 done 而非 crash）。
- **不变**：Tools seam 本身仍"抛错原样传播"——直接调用 `tools.execute` 的调用方拿到的
  还是 rejection；归一化是 loop（唯一消费方）的约定。

### 2. edit_file 字面替换（$ 序列）

- **改法**：`packages/tools/src/fs.ts` 用函数替换器 `text.replace(oldText, () => newText)`，
  newText 里的 `$&`/`$$`/`` $` ``/`$'` 按字面写入，不再被解释为替换模式。

### 3. 悬空工具调用：崩溃恢复合成结果 + 投影防护（双保险）

- **改法 A（日志层）**：`repairDanglingTurn` 现在对崩溃轮里"声明过但结果没回来"的工具调用
  合成 isError 结果事件（按 projectMessages 同款顺序配对；name/arguments 取自 assistant
  声明），补在 `turn/end(crash)` 之前；`repaired` 由单事件改为**事件数组**（manager 逐条落盘）。
  补写事件 ts 取最后一条日志的 ts（不再用 `Date.now()`——顺带修掉审计清单 B7#33）。
- **改法 B（投影层）**：`projectMessages` 对配对队列里剩余的悬空调用补 isError 错误结果
  消息（toolCallId 用原调用 id），触发点 = 任何会打断 wire 相邻性的消息（下一轮 user /
  下一个 assistant）到来前与投影结束时——保证**任何**日志（含 limit 轮、未修复的旧日志）
  投影出的 transcript 都 wire 合法。
- **为什么两层**：日志层让轨迹如实显示"调用被中断"（上游 repair 同款）；投影层兜住
  repair 覆盖不到的场景（limit 轮、跨轮遗留），provider 不会再因悬空 tool_calls 拒绝输入。

### 4. loadProfile 失败路径 dispose

- **改法**：`packages/kernel/src/profile.ts` 装载循环整体 try/catch；失败时先
  `ctx.fiber.dispose()` 撤销已装载插件（硬约束 6 的启动侧落地）再上抛原始错误
  （清理失败不掩盖原始错误）。新增 fixture + 测试断言失败后 effect 清理必跑。

### 5. MCP 重同步串行化 + 连接代栅栏

- **改法**：新增 `packages/mcp/src/sync-queue.ts`（代际同步队列：串行执行、入队时捕获代、
  revoke 使代失效；未开始的同步跳过、在途同步完成后其结果被 disposeResult 回收、绝不
  commit）；`mcp-client` 的初始同步 / list_changed 重同步都走队列，`onclose` 先
  `revoke()` 再撤销当前持有。
- **修掉两个竞态**（上游 `syncChain`/`isCurrent` 的 mini 版）：并发重同步丢一代撤销函数
  → 工具永久滞留注册表；onclose 与在途重同步竞态 → 死工具回流注册。

### 6. subagent 生命周期事件监听器异常隔离

- **改法**：`packages/subagent/src/service.ts` 的 `start()` **先挂 result 配对观察、再
  emit** `subagent/start`；三个 emit 点全部 try/catch + logger.warn（workflow 引擎同款
  纪律）。坏监听器抛错不再打断 start 兑现（调用方必拿到 run 句柄）、不再留下孤儿 start。
