# Web 空态 UX：大新建会话按钮 + 聊天区吸底（2026-08-16）

## 无会话空态（用户点名）

`--clean` 启动后没有会话可聊，原 UI 却把 chatbox 亮在中间（发送按钮禁用、提示
"新建或选择一个会话"）。改为：

- chatbox 整体不渲染（"ban 掉"采用隐藏而非置灰：无会话时输入框没有意义，
  隐藏最干净；想要置灰版本可再改）；
- 中间给大的「＋ 新建会话」按钮（`.dsh-start-session`），点它 = 调
  `store.create()`，与左侧小按钮同一动作；
- 创建成功后 composer 出现并自动聚焦输入框（`useEffect` 监听 `currentId`）。

## 自查发现并一并修的 UX 问题

1. **有会话但还没消息时提示语误导**：原文案仍是"新建或选择一个会话"，
   改为"开始和模型对话吧——输入消息，Enter 发送"。
2. **新消息不吸底**：聊天区滚动修复（上一决策）之后，长对话中流式回复
   会一直长在视口下方看不到。实现吸底：`useLayoutEffect` 在消息变化时
   `scrollTop = scrollHeight`；用户上翻（距底 >80px）后暂停吸底，不再打扰阅读。
3. **会话列表空态**：无会话时补"还没有会话"提示。

## 测试

- jsdom 断言：无会话时 `.dsh-composer` 为 null、大按钮存在；点按钮创建会话后
  composer 出现且 `document.activeElement` 是输入框；空会话提示语新旧文案；
  吸底用接管 `scrollHeight`/`scrollTop` 的假元素断言（jsdom 无布局引擎），
  并覆盖"用户上翻后不吸底"。
- 全量 271 测试绿；构建冒烟含高度链 CSS 断言（上一决策）。
